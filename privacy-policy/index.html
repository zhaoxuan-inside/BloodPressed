血压了么隐私政策

更新日期：2026年10月15日　生效日期：2026年10月15日

运营者：赵宣
联系邮箱：zhaoxuanmail@163.com

本政策适用于赵宣提供的“血压了么”（BloodPressed）应用。应用用于记录血压、查看趋势、识别血压计读数及提供健康信息参考，不提供医学诊断或治疗服务。请在使用相关功能前了解下列个人信息处理规则。

血压、脉搏、测量时间及相关备注可能涉及医疗健康等敏感个人信息。处理这些信息是为了实现您选择的记录、统计、识别或分析功能。泄露或不当共享可能影响您的个人隐私；请谨慎决定是否输入、导出、分享或提交给远端服务。您可以不使用语音、拍照、远端 AI 等可选功能，改用手动记录。

一、记录、设置与本地存储

您主动填写的收缩压、舒张压、脉搏、测量时间、测量臂、体位、备注及记录来源，保存在设备上的应用数据库中，用于记录管理、分级提示、趋势统计和导出。拍照或相册识别产生的照片副本、知识文章收藏、字号和提醒等偏好也保存在设备本地。

应用会随机生成应用实例标识（UUID），用于本地记录标记及预留的同步变更记录；它不是读取手机 IMEI、OAID、MAC 地址生成的硬件标识。当前版本的云同步尚未接入远端平台，本地同步队列不等于已上传数据。

当前应用无注册账号、广告投放或行为统计服务。运营者没有接收和集中存储血压记录的自建业务服务器。上述说明不代表可选远端 AI、模型下载、系统服务和您主动分享时完全没有网络数据传输，具体见下文。

二、拍照、相册与语音录入

当您选择拍照识别时，应用请求相机权限并调用系统相机；选择相册时，应用通过系统图片选择器读取您选定的图片。当前血压计照片识别入口使用本地七段码解析和 PP-OCR 推理，不会在该流程中自动将照片发送给远端大模型。为保存识别记录，照片可能被复制到应用私有目录；识别失败或置信度较低时，应用还可能在本地保存输入图片、处理过程图片和诊断摘要，用于排查识别问题。

当您选择语音录入时，应用请求麦克风权限。应用优先尝试手机提供的系统语音识别服务；该服务是否联网以及如何处理音频，取决于您手机的系统、语音服务提供方及其设置和政策。系统服务不可用时，应用使用随安装包内置的 sherpa-onnx 模型进行本地识别，该离线引擎不向远端上传麦克风音频。

应用不会主动将语音录入保存为录音文件；识别结果用于填写记录表单。您拒绝相机、相册或麦克风相关授权，只会影响相应可选功能，不影响手动记录。您可在系统的应用权限设置中撤回授权。

三、本地 AI、远端 AI 与模型下载

使用本地大模型时，推理在设备上进行；为使用本地大模型而下载模型文件是网络请求，与将健康数据提交给远端 AI 是不同的操作。

当您主动配置、选择并使用远端 AI 对话或趋势 AI 分析时，应用会向该配置所指向的服务端发送问题、对话上下文及功能所需的血压数据。健康助手会附带近 30 天的血压统计摘要、最近一次记录和相关测量信息；趋势分析还可能包含您选择时间范围内的数据摘要。请求使用您填写的接口地址、模型名称及 API Key 进行认证。API Key 和模型配置保存在应用本地，应用没有将它们交给运营者的服务器。

远端服务提供方能够接收上述请求内容以及完成网络连接所需的 IP 地址等信息；具体保存期限、是否用于训练和权利行使方式由所选服务及其政策决定。当前版本要求您先填写服务实际运营者、隐私政策 HTTPS 链接并核实处理地域为中国大陆，同时使用不含内嵌凭证的 HTTPS 服务地址，才可单独授权发送健康信息。处理地域未核实或位于境外的服务暂不开放健康信息发送；仅勾选或同意并不能代替法律要求的跨境条件。

模型中心搜索及模型文件下载会连接魔搭社区（modelscope.cn）、Hugging Face（huggingface.co）或当前配置的镜像（如 hf-mirror.com），并可能跟随资源下载的重定向访问存储/CDN。接收方可获得搜索词、仓库/文件标识、请求 IP 等网络信息；正常模型搜索下载请求不包含您的血压记录或 AI 对话。

远端 AI 或镜像的接收方取决于您的配置和请求实际到达的域名，并非均由运营者提供。相关服务的隐私政策应在使用前查阅；您可以删除远端配置、停止使用相关功能，或撤销/更换服务商的 API Key。

首次向某个服务发送健康信息前，应用会单独显示接收方、服务地址、模型、隐私政策和发送范围，您明确单独同意后才会发送。授权与配置档案、服务地址、模型、接收方说明和告知版本绑定；变更后重新确认。您可在“我的 → 撤回远端 AI 授权”停止当前回复并清除授权，拒绝不影响本地记录或本地模型。已发送到服务商的数据不能从本机撤回，请联系服务商行使相关权利。

四、导出、系统分享与微信

导出 CSV、记录卡或趋势/分析卡时，应用在设备上生成所选内容，可能包含您的血压、脉搏、测量时间及统计摘要。只有在您发起导出或分享后，相应文件或文本才会交给您选择的接收应用或分享渠道；该接收方之后如何处理数据，适用其自身规则。

未配置微信开放平台参数时，分享通过系统分享面板完成，您仍可在面板中选择微信。兼容已有微信原生配置的功能仍包含 fluwx 封装的微信 OpenSDK；存在有效配置时，应用在您同意隐私政策后才会注册该 SDK，并在分享时检测微信安装状态、传递您选定的图片或文本以及分享目标。SDK 的设备、应用和网络信息处理规则请查看微信官方指引：https://support.weixin.qq.com/cgi-bin/mmsupportacctnodeweb-bin/pages/RYiYJkLOrQwu0nb8 。本应用不提供微信登录或微信支付。

请仅向您信任的联系人或平台分享健康数据。取消分享不等于能够撤回已由接收方保存的副本。

五、提醒、权限与第三方组件

提醒功能通过 flutter_local_notifications 使用设备本地通知和定时能力，在您设置的时间提醒测量；可能需要通知权限和系统允许的定时能力。flutter_timezone 用于读取系统时区，以正确计算本地提醒时间，不需要获取精确地理位置。关闭提醒或撤回通知权限后，相应提醒将受影响。应用不接入 OPPO/vivo 等厂商的远程推送 SDK。

主要本地处理组件包括 image_picker（系统相机/选图）、permission_handler（权限状态与申请）、speech_to_text（调用系统语音服务）、record 与 sherpa_onnx（离线语音）、onnxruntime（本地 OCR）、llamadart（本地大模型）、sqflite/shared_preferences（本地保存）及 share_plus（系统分享）。这些组件在本应用中的用途是调用系统能力或本地处理；它们不等同于广告或分析平台。

微信 OpenSDK 由腾讯提供；远端模型接口、模型社区、镜像和手机系统语音服务由相应第三方提供。只有调用相关功能时，才应结合实际服务确认接收方和处理规则。系统及组件为了执行您选择的功能，可能处理必要的设备型号、系统版本、应用信息、网络状态或权限状态。拒绝某项可选权限不影响其他独立功能。

本政策网页使用 GitHub Pages 托管，正文不加载广告、统计脚本或外部字体。访问网页会向 GitHub 发起网络请求；GitHub 说明其为安全目的记录访问 IP，具体见其隐私声明：https://docs.github.com/en/site-policy/privacy-policies/github-general-privacy-statement 。阅读政策网页不需要提交血压记录。

六、保存期限、删除与安全

本地记录、照片副本、诊断文件、模型、对话和设置通常保留在应用目录，直至您删除相应内容、清除应用数据或卸载应用。设备系统的备份/恢复行为取决于您的系统设置，可能需要您同时管理系统备份和自行导出的文件。

记录列表中的删除目前采用软删除：记录不再正常显示，但本地数据库、同步变更日志或相关照片中可能仍保留副本。若您希望彻底删除应用本地数据，可先自行保存需要的内容，再通过系统设置清除应用存储数据或卸载；导出后保存到其他位置的文件、接收应用中的副本及远端服务中的内容需分别管理。

应用使用操作系统提供的应用私有存储边界保存数据，不能据此视为所有记录或 API Key 均已单独加密。请保护设备解锁凭据，谨慎使用云备份、共享设备和来历不明的远端接口。任何网络或存储措施都不能保证绝对安全。

七、您的选择与权利

您可在应用中查看、更正、删除记录，导出记录副本，修改提醒和模型配置，并在系统设置中管理权限。当前版本没有账号注册机制，因此没有应用账号注销操作；删除本地数据的方式见上一节。

对于您主动使用的远端服务，请同时依据其规则提出查阅、复制、更正、删除或撤回相关授权的请求。运营者通常无法代替您删除服务商保存的数据。

如需咨询个人信息处理、行使相关权利或投诉，请联系 zhaoxuanmail@163.com。我们可能在必要范围内核实请求真实性，并依据适用法律处理请求。请勿在普通邮件中附上不必要的完整健康记录或 API Key。

首次使用或告知版本更新时，应用先提供可离线阅读的政策及同意/暂不同意选项；未同意前不打开业务数据库、不生成应用实例标识、不启动模型或注册微信分享 SDK。您可在“我的 → 撤回隐私同意”撤回总体授权，应用停止业务会话及提醒并返回说明页面。已有本地记录和配置保留，重新进入需再次同意；彻底删除可按前文清除应用存储。
