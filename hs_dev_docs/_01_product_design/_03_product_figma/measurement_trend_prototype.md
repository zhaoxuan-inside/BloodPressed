# 原始测量趋势与脉压差

用户确认：保留每次测量，不取日均值；允许只保存高压或低压，缺失项留空。

- 时间轴使用日期＋真实时刻；单日显示时刻，多日显示日期，缩放不改变原始样本。
- 每条记录分别绘制红色高压、蓝色低压；一天一次显示点，一天多次全部显示。
- 整天无测量或当前指标缺失时断线，不补零、不插值。疑似错误保留原值并标记需核对。
- 下方紫色脉压差图与上方共用时间范围和缩放；仅用同一次完整有效的高压减低压。
- 点击点显示原始时间、左右臂、血压、脉压差、脉搏和数据状态；下方显示当天各指标首次/末次/最低/最高。
- 同一时间的多条记录不覆盖，提示中列出全部同刻记录。
- 顶部展示记录数、完整有效血压数和整天缺测数。规律分析仅使用完整有效的成对记录，并说明口径。
- 全屏和分享卡复用同一原始数据绘图；静态分享禁用交互，包含高低压范围、压差范围及次数。

## 页面布局

筛选日期与臂 → 分项统计 → 血压/脉搏切换 → 原始血压折线 → 独立脉压差折线 → 点选当日摘要 → 完整成对记录的规律分析。

真实 SQLite v1→v2 升级及旧数据保留；表单单项保存/编辑清空；Provider 新增、缺项编辑、改日期及删除刷新；原始坐标、缺日/缺项路径、压差同次配对、窄屏及分享 PNG。


## 同日密集测量的可读性修复

用户反馈：在多日真实时间总览中，同一天多次测量仍被压在很窄的位置，无法看清日内波动。

- 趋势页提供文字入口“查看单日趋势”；全屏页提供同名提示图标，默认打开当前范围内最近有记录的一天，并沿用左右臂筛选和血压/脉搏选择。
- 单日页可选日期、前后逐日浏览；缺测日期明确显示当天无记录。
- 单日图按实际测量的先后顺序，每条记录独立占位（含同刻记录），每条至少预留 88 逻辑像素，标注序号和实际时刻；超过屏宽时同步横滑血压和脉压差。
- 页面明确说明“间距不代表时长”；原多日总览继续使用真实时间轴，不能把两种坐标语义混淆。
- 单日图直接标数字，高压数值在点上方、低压在点下方，脉压差单独显示；数字字体沿用应用主题，滚动条不遮挡时间标签。
- 缺项继续断线，缺压差显示空态；下方逐条展示实际读数，点击可编辑，保存后通过 Provider 自动重查。
- 验证：原实现缺少单日入口的 UI 回归先失败；密集/同刻测量独立坐标、横滑、缺项断点、日期切换、空日期与编辑刷新通过；实际 Flutter PNG 视觉检查。
