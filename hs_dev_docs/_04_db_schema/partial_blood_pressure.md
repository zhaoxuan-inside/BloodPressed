# 单项血压与数据库版本 2

用户已确认允许只保存高压或低压。未知项保留 SQL NULL，禁止用 0 或其他记录补齐。

- bp_records.systolic / diastolic 从 INTEGER NOT NULL 改为 INTEGER；其他字段和表不变。
- 至少一个血压字段有值；已填写项沿用既有范围校验，两项齐全时继续校验高压大于低压。表单、Controller 和 Repository 保存时执行同一校验。
- copyWith 省略字段保留原值，显式 null 清空字段；序列化和 outbox 保留 null；CSV 对应单元格为空。
- 升级在 sqflite onUpgrade 的事务中重建记录表，复制所有列，恢复测量时间/同步状态索引；outbox、模型和聊天表保留。升级失败由事务回滚；旧版应用不支持打开版本 2，不能通过降级丢弃空值。
- 统计的高低压均值/极值按各自有效样本计算，无样本返回 null。达标率以完整有效的成对记录为分母，无完整样本返回 null。
- 脉压差只使用同次完整有效血压。规律分析也使用完整有效配对，UI 明确说明口径。趋势保留所有原始测量与缺失位置。

测试：partial_records_test 的真实 v1 文件升级、全字段保留、outbox/聊天保留、索引恢复、单项新增与清空、序列化及分项统计。
