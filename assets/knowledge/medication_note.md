# 吃药的高血压患者，为什么要坚持自测？

不少患者觉得"药已经开了，测不测无所谓"，这其实错失了药物治疗中最重要的反馈环节。

## 自测对服药者的四大价值

### 1. 验证药效
降压药是否对你"剂量合适、时段合适"，只有靠家庭自测数据回答。医生调药时最想看到的就是你在家的一周记录。

### 2. 发现晨峰
很多心脑血管事件发生在清晨。早晨服药前测一次，能发现药物是否覆盖了"晨峰时段"——这是诊室随机测压发现不了的。

### 3. 警惕低血压
降压的目标不是"越低越好"。过度降压会头晕、跌倒，尤其老年人。如果自测发现高压经常 <100，或站立时头晕明显，请及时联系医生调整。

### 4. 提高依从性
看见数字因服药而改善，是最直接的"正反馈"。研究显示坚持家庭自测的患者，服药依从性和血压达标率都显著更高。

## 服药者的测量方案

- **早晨**：起床后、服药前、早饭前（覆盖药效谷值 + 晨峰）
- **晚上**：睡前 1 小时
- 每次测 2 遍取平均
- 换药 / 调剂量后的 **1~2 周**加密测量

## 常见问题

**Q：吃了药血压正常了，可以停药吗？**
A：不可以自行停。血压正常恰恰是药物在起效的表现，突然停药可能引起血压反弹。任何加减药都请与医生商量。

**Q：忘记吃药怎么办？**
A：想起时当天补上；已接近下一次服药时间就跳过，切勿一次服双倍剂量。

**Q：能凭感觉吃药吗？**
A：不能。血压高低与症状不平行，"没感觉"不等于血压正常。
