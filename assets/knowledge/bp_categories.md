# 血压分级：你的读数处于什么水平？

本应用按**家庭自测标准**对每次读数进行分级显示，颜色含义如下：

## 🟢 正常（绿色）
高压 < 130 且 低压 < 85

理想状态。继续保持规律测量和健康生活方式。

## 🟡 正常高值（黄色）
高压 130~139 或 低压 85~89

"临界区"。此时生活方式干预效果最好：减盐、运动、减重、规律作息，很多人可以回到绿色区。

## 🟠 轻度升高 / 1 级（橙色）
高压 140~159 或 低压 90~99

达到高血压水平（家庭自测标准）。建议：
- 连续测量 5~7 天，把记录带给医生
- 医生可能建议生活方式干预 ± 药物治疗

## 🔴 中重度升高 / 2 级及以上（红色）
高压 ≥ 160 或 低压 ≥ 100

**建议尽快就医**，不要拖延。若同时有头痛、胸闷、视物模糊等症状，应立即就诊。

## 🟣 偏低（紫色）
高压 < 90 或 低压 < 60

如果没有头晕、乏力等症状，一般无需处理；若症状明显或正在服用降压药，请咨询医生是否需要调整方案。

---

> 📌 分级依据单次读数，**趋势比单点更重要**——请结合趋势图和医生意见综合判断。
